# 繪本島・備份同還原 log

## 呢度有咩 file
- `island.html`＝成個網站（唔好改名，雙擊 .bat 開佢）
- `notes.json`＝所有書嘅文字（老師模式匯出會覆蓋呢個）
- `island-settings.json`（喺 Downloads）＝你撳「⬇ 設定備份」匯出嘅嘢：島名、外觀、樓層、傢具、書櫃位置、天氣
- `backup\YYYYMMDD-HHMMSS\`＝每次大改前嘅 snapshot，入面齊晒上面三樣

## 改大嘢之前：備份（10 秒）
雙擊 `備份.bat` → 自動起個日期 folder，copy 齊三樣嘢入去。
幾時要備份：加／刪島、轉樓層、搬書櫃之前。平時改書名加書唔使（即存 browser）。

## 炒咗點還原（跟次序）
1. 設定（島、傢具、書櫃位）：開老師模式 → 左下「⬆ 還原設定」→ 揀返 backup 入面嘅 `island-settings.json`
2. 書：如果書唔見咗：開返 backup 入面嘅 `notes.json`，成個貼返去老師模式 → 書 → 匯出／貼上（或直接 copy 蓋過呢度個 `notes.json` 再 F5）
3. 網站本身爛咗（白版／撳極冇反應）：去 backup 搵最近期又正常嗰日，copy 個 `island.html` 出嚟蓋過呢度個，再 F5
4. 見 404 / 開唔到：係後面個黑窗 server 瞓咗，閂晒所有黑窗再雙擊開網站 .bat；唔得就 Ctrl+F5 硬重新整理（舊 code 藏喺 cache 會搞到 menu 打唔開）
