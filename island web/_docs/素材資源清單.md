## 陷阱清單（最常中招）

1. **「Free」≠ 可商用 ≠ 可再分發。** Mixamo 免費但唔可以派原始檔；Kenney 免費而且可以派。
2. **CC-BY-SA 有傳染性。** 你嘅成品要同樣以 CC-BY-SA 開放。
3. **CC-BY-NC 不可商用。** 校內教學一般算非商業，但賣給其他學校就唔得。
4. **「內嵌」同「派檔」係兩件事。** 把素材 base64 塞入 HTML 再派出去，實質上係分發該素材 → 只有 CC0（或明確允許再分發）才安全。
5. **角色 IP 一律不可。** Star Wars、Pokemon、Lego、Marvel 的 fan-made 模型，就算作者寫「免費」都無權授權。
6. **AI 生成素材**視乎平台條款，多數聲稱可商用但無法律先例；學校教材建議避免。
7. **字型**：用系統字型（微軟正黑體）零風險；嵌入 webfont 要睇 OFL 條款。

## 每次下載素材的 5 步驗證

1. 開 zip，**搵 LICENSE / licence.txt** —— 冇就要去官網授權頁
2. 確認授權類型（CC0 / CC-BY / 自家）
3. 記錄：**來源 URL + 授權 + 下載日期**
4. 把 LICENSE 檔存去 `_licenses/`（本專案已建此資料夾）
5. 成品內加一個 **credits 區**（本專案已加「ⓘ 素材授權」按鈕 + `<head>` 註解）
